# Project 1 — Smart Utility Console

## Client Background

A small office currently uses several different websites and applications for everyday calculations and utilities.

Employees often switch between multiple tools just to perform simple tasks such as calculating percentages, converting temperatures, checking BMI, or generating multiplication tables.

The management wants to replace these scattered tools with a single console-based application that is simple, fast, and easy to use.

You have been hired to develop the first version of this application.

---

# Project Objective

Develop a menu-driven console application called **Smart Utility Console**.

The application should provide multiple everyday utilities from a single interface.

Users should be able to select a utility, perform a task, return to the main menu, and continue using the application until they choose to exit.

The application should be easy to read, easy to navigate, and simple enough for non-technical employees to use.

---

# Functional Requirements

Your application must provide the following utilities.

### 1. Basic Calculator

Allow users to perform basic arithmetic operations.

The calculator should support:

- Addition
- Subtraction
- Multiplication
- Division

---

### 2. Percentage Calculator

Allow the user to enter:

- Obtained Marks
- Total Marks

Display the calculated percentage.

---

### 3. BMI Calculator

Allow the user to enter:

- Weight (kg)
- Height (meters)

Display:

- BMI
- BMI Category

---

### 4. Temperature Converter

Allow users to convert temperatures between:

- Celsius → Fahrenheit
- Fahrenheit → Celsius

---

### 5. Age Calculator

Allow users to enter their birth year.

Display their current age.

---

### 6. Student Grade Calculator

Allow users to enter marks for multiple subjects.

Display:

- Total Marks
- Percentage
- Grade

You may define your own grading criteria.

---

### 7. Password Strength Checker

Allow the user to enter a password.

Display whether the password is:

- Weak
- Medium
- Strong

Choose reasonable rules to determine password strength.

---

### 8. Multiplication Table Generator

Allow the user to enter a number.

Display its multiplication table.

---

### 9. Number Utility

Allow the user to enter a number.

Display useful information such as:

- Even or Odd
- Positive or Negative
- Square
- Cube

---

### 10. Exit Application

Allow users to close the application safely.

---

# Client Requirements

The client has provided the following expectations.

### Menu Driven Application

The application must contain a clear main menu.

The user should always know which options are available.

---

### Continuous Execution

After completing one operation, the application should automatically return to the main menu.

The application should continue running until the user selects the Exit option.

---

### User-Friendly Output

Display clear headings and meaningful messages.

Organize the output neatly so users can easily understand the results.

---

### Code Reusability

Avoid writing the same code multiple times.

If multiple utilities perform similar operations, organize your program so the logic can be reused.

---

### Readability

The client expects clean and organized code.

Someone else should be able to understand your program without difficulty.

---

# Technical Expectations

Before writing code, spend time planning your solution.

Think about questions such as:

- How should the main menu work?
- How can users repeatedly perform different tasks?
- Which parts of the program are repeated?
- How can the program be organized into smaller pieces?
- How can future utilities be added without rewriting large portions of the application?

Design your program so that adding a new utility in the future requires minimal changes.

---

# Development Guidelines

While designing your application:

- Break large problems into smaller tasks.
- Give meaningful names to variables and functions.
- Display clear prompts for user input.
- Keep the user experience simple.
- Test every utility before moving to the next one.
- Think about how real users might interact with your application.

Remember:

A working program is good.

A well-organized and reusable program is even better.

---

# Deliverables

Your final submission should include:

- A fully functional menu-driven application.
- All required utilities.
- Clean and organized code.
- Meaningful variable and function names.
- Proper formatting for all displayed information.
